# Prueba Técnica Topaz

Repositorio con la solución de la prueba técnica.

## Contenido

### Java

Archivo: `evaluacion_logica_topaz.java`

Contiene la solución de los ejercicios de lógica relacionados con el manejo de una matriz:

* Búsqueda de un número y ubicación dentro de la matriz.
* Identificación del número mayor y su posición.
* Llenado de las diagonales con ceros.

### SQL

Archivo: `evaluacion_bd_topaz.sql`

Contiene las consultas y soluciones correspondientes a la evaluación de base de datos:

* Consultas de clientes.
* Conteo de clientes por país.
* Filtros por apellido y país.
* Identificación de campos que pueden ser `NULL`.
* Restricciones de valores.
* Validación para evitar registros duplicados.
* Consulta adicional de países con menos de 10 clientes.
